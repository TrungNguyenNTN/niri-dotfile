# Archlinux + Niri + Noctalia V5 (beta)


## Package
- **Terminal**: kitty
- **File Manager**: nautilus
- **Browsers**: firefox
- **TUI**: fastfetch, cava, cmatrix, htop, btop, cava, lavat-git(AUR) , tty-clock-git(AUR), pipes.c(AUR)
- **fastfetch logo**: figlet, lolcat
- **Shell**: zsh
- **Zsh Plugin && config**: git-zsh-completion  grml-zsh-config zsh-autosuggestions zsh-history-substring-search zsh-syntax-highlighting
- **Zsh theme**: starship
- **Noctalia**: noctalia-git(AUR) , evolution-data-server

## Core Binds
- Mod + T: Open kitty
- Mod + B: Open firefox
- Mod + E: Open nautilus
- Mod + S: Control Center
- Mod + P: session
- Mod + Alt + L: Lock screen
- Mod + Shift + W: Walpaper board
- Mod + Space: App Launcher
- Mod + Shift + C: clipboard
- Mod + Shift + Comma: Open Noctalia Setting (*Edit the interface here*)
